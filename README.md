# Telegram 多群积分机器人

一个轻量的 Telegram 群组积分机器人：聊天、签到获得积分，管理员负责调整规则和成员积分。

## 1. 安装

服务器需要 Python 3.10+（推荐 3.11+）。从 GitHub 拉取并安装依赖：

```bash
git clone https://github.com/albertyizhan/telegram-points-bot.git
cd telegram-points-bot
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
chmod +x manage.sh
```

第一次运行 `./manage.sh start` 会自动生成本地 `.env`。编辑它：

```dotenv
BOT_TOKEN=从 BotFather 获取的 Token
OWNER_ID=总管理员的 Telegram 数字 ID
# DB_PATH=points.db
```

在 BotFather 使用 `/setprivacy`，选择机器人并设为 **Disable**，或将机器人设为群管理员。修改后将机器人移出群再重新加入，否则它可能收不到普通聊天消息和“签到”等非斜杠别名。

启动和管理：

```bash
./manage.sh start       # 后台启动
./manage.sh status      # 查看状态和最近日志
./manage.sh stop        # 正常关闭
./manage.sh restart     # 重启
./manage.sh update      # 拉取 GitHub 更新、安装依赖并重启
```

`manage.sh` 会自动进入项目目录并读取 `.env`。`run` 命令可前台运行用于调试；进程卡住时使用 `./manage.sh stop --force`。

数据库使用 SQLite，已启用 WAL、正常同步和写入等待，适合每天几千条群消息的小型服务。使用 `./manage.sh backup` 创建在线备份，机器人运行中也可安全执行；备份默认保存在 `backups/points-YYYYMMDD-HHMMSS.db`。脚本会读取 `.env` 中的 `DB_PATH`，相对路径以项目目录为基准，源文件不存在时直接报错。不要单独复制正在使用的数据库或 WAL/SHM 文件。

每天备份一次的 cron 示例（替换为实际项目路径）：

```cron
0 3 * * * cd /root/telegram-points-bot && BACKUP_KEEP=14 ./manage.sh backup >> bot.log 2>&1
```

按本项目禁止批量删除的规则，`BACKUP_KEEP=14` 会列出超过最近 14 份的旧备份供你手动删除，不自动清理。

## 2. 激活群组

1. 总管理员私聊机器人发送 `/start`，点击“生成群组激活码”。
2. 把激活码发给群主。
3. 群主在目标群发送 `/activate 激活码`。

激活码第一次使用后会绑定该 Telegram 用户。每个用户最多激活 3 个群；机器人拥有者不受此限制。停用群组只停止积分统计，不删除已有数据。

## 3. 日常使用

默认规则：消息去掉空白后至少 5 个字符，每条获得 1 分，每日聊天积分上限 20 分；每日签到奖励 5 分，签到不占聊天上限。日期按群组时区结算，默认 UTC+08:00。

群成员可以使用：

```text
/score       查看自己的总积分、今日聊天积分和签到状态
/checkin     签到并领取每日奖励
/rank        查看累计积分排名
/today       查看今日积分排名
```

群管理员可以使用：

```text
/addpoints 10 @username   增加成员积分
/subpoints 10 @username   扣除成员积分
```

也可以回复成员消息后发送 `/addpoints 10` 或 `/subpoints 10`。回复真实成员的消息即可为其建立积分记录；按用户名查找时，成员须已有群内记录。

## 4. 私聊管理

私聊机器人发送 `/start`，先选择群组。群组主页直接提供：

- 语言
- 地区（时区）
- 成员积分
- 今日排名和累计排名

权限按 Telegram 当前身份划分：

- 1 级：普通群管理员，可查看成员、排名、调整与撤销积分，也可激活群组。
- 2 级：拥有“添加管理员”权限的管理员，还可修改规则、别名、语言、时区和导入数据。导出与导入均要求 2 级以上。
- 3 级：群主，拥有全部群管理权限。`OWNER_ID` 总管理员同为 3 级，另可生成激活码、查看全部群组并停用群组。

2 级以上可使用：

- 积分规则
- 自定义命令
- 积分调整记录
- 导出数据、导入数据和查看导入记录

成员查找支持 `@用户名` 或数字 ID。单人成员积分回复优先显示 `@用户名`，未设置用户名时显示昵称；排名和历史列表使用不会触发 @ 提醒的显示名；管理页面保留 ID 便于核对。调整记录分页展示时间、操作者、增减分数、前后积分和原因。

调整记录显示记录编号，并提供撤销按钮。撤销需要确认，只反向抵消该条记录，不影响其他积分变动；每条记录只能撤销一次，撤销本身也会留下记录。今日和累计排名均可通过管理菜单继续翻页。

导出和导入只能通过群组主页按钮执行。导出的 JSON 文件包含绑定的群组 ID；导入入口有效期为 10 分钟。机器人先显示新增、变化、不变人数与总分差额，确认后先做在线备份，再写入数据；分数变化逐人记录且不可单条撤销，需要回退时使用导入前的备份。文件属于其他群组时拒绝操作。导入记录按群组分别保存，包含时间、操作者和处理成员数。

导入文件最大为 10 MB；成员积分、每日记录、日期和签到状态会先校验，写入失败时整批回滚。导入记录同时显示编号和来源。搜索失败后可点击“重新搜索”，返回菜单会退出未完成的输入流程。

语言和时区按群组分别保存。每日结算时区会影响签到和每日聊天积分上限的日期边界。消息长度和聊天积分上限填 0 表示不限制；签到奖励填 0 表示签到不奖励积分。

