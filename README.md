# Telegram 多群积分机器人

这是一个单文件、SQLite 持久化的最小可用机器人，支持多群独立积分、聊天积分、签到、个人授权码、群命令别名、管理员增减积分和私聊 Inline Keyboard 后台。

## 创建机器人

在 Telegram 找 `@BotFather`，发送 `/newbot`，按提示设置名称和用户名并复制 Token。再发送 `/setprivacy`，选择机器人后设为 `Disable`，否则机器人收不到普通群消息。建议把机器人设为群管理员，以便可靠读取群管理员权限和成员消息。

## 安装与启动

需要 Python 3.9+。在服务器执行以下安装命令（项目会从 GitHub 拉取）：

```bash
git clone https://github.com/albertyizhan/telegram_points_bot.git
cd telegram_points_bot
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
chmod +x start.sh
```

编辑 `.env` 填入 `BOT_TOKEN` 和 `OWNER_ID`，然后启动：

```bash
./start.sh
```

`start.sh` 会固定在项目目录运行并读取 `.env`，前台保持进程，便于交给 systemd、Supervisor 或其他进程管理器托管。

`OWNER_ID` 是总管理员数字 ID。可用 `@userinfobot` 获取用户 ID；群组 ID 可在激活后由机器人使用，不需要手填。数据库默认是当前目录的 `points.db`，可用 `DB_PATH` 改路径。

需要核对群组 ID 时，可将群消息转发给 `@RawDataBot` 查看 `chat.id`；本机器人本身始终按收到消息的群组 ID 隔离数据。

## 授权群组与个人授权

总管理员私聊机器人发送 `/start`，点击“生成授权码”，把只显示一次的授权码发给群主。群主在目标群发送：

```text
/activate 授权码
```

授权码第一次使用后永久绑定该 Telegram 用户，数据库只保存 SHA-256 哈希。绑定用户之后在自己的其他群发送 `/activate` 即可激活，每个用户最多 3 个启用群，多个授权码不能叠加。重启不会丢失绑定；撤销群组只停用该群，不会删除积分数据。机器人拥有者（`OWNER_ID`）可在任意数量群激活，并可管理全部群。

总管理员可在私聊后台查看未使用码（仅显示哈希前缀）和已授权群。

## 管理员权限

- 1 级：群内任意管理员，可查看统计和调整成员积分。
- 2 级：拥有“添加新管理员”权限的管理员，在 1 级基础上可修改设置和命令别名。
- 3 级：群主，在 2 级基础上拥有全部群组管理权限；总管理员拥有所有群的 3 级权限。

激活群组本身要求发送者是群主或管理员，并且使用自己绑定的个人授权额度。

## 群内命令

机器人启动时会自动注册命令菜单。在群聊或私聊输入 `/`，Telegram 会显示可直接点击的核心命令；群组自定义别名仍在机器人后台中按群解析。

```text
/score
/checkin
/签到
/addpoints 10 @username
/subpoints 10 @username
/rank
/today
回复成员消息后发送：/addpoints 10
回复成员消息后发送：/subpoints 10
```

`/rank` 显示总积分排行，`/today` 显示单日积分排行，每页 15 人，可在机器人消息下方翻页。

私聊 `/start` 后选择群组，可以查看/修改最小字数、每日聊天上限、签到积分、语言和时区，管理别名、成员积分和前 20 名统计。语言可切换中文/English；点击“选择时区 / Timezone”后会展开 UTC-08:00 到 UTC+12:00 的列表，时区会影响每日签到和每日聊天上限的日期边界。设置页面显示中文名称，例如“每日聊天积分上限”，不会显示 `daily_limit` 变量名。

机器人拥有者的 `/start` 后台支持群组分页浏览（每页 8 个）和按完整群组 ID/群名关键词搜索。撤销群组授权需要再次点击“确认撤销”，可避免误触；撤销只停止该群统计，不删除积分数据。

拥有者首页分为“您管理的群组”和“管理已授权群组”。后者只用于选择并解除授权，不会误进入群组设置。

成员搜索只接受完整数字 Telegram ID；用户名只能匹配机器人已经在该群记录过且完整、忽略大小写的用户名，Bot API 无法查询任意用户名。

默认设置：去除空白后最少 5 个字符，每人每天最多 20 条聊天积分，每日签到 +5。命令、签到和机器人消息不计聊天分。

设置为 `0` 的含义：最小字数为 0 表示不设最低字数（空白消息仍不计分）；每日聊天积分上限为 0 表示无限制；签到积分为 0 表示签到不加分。

## 数据备份

机器人不提供服务器端或后台导出/导入功能。每个群主负责自行备份本群资料；数据库文件位置由 `DB_PATH` 决定，默认是项目目录下的 `points.db`。

## 测试

```bash
.venv/bin/python -m unittest -v
```

测试直接覆盖 SQLite 规则，不访问 Telegram 网络。
